# 助理行政小工具

用來做紅包袋和獎狀。打開網頁、填好資料，就能下載 Word 檔。

**[開啟工具](https://nasircy.github.io/cge_tools/)**

## 紅包袋怎麼做

1. 點「紅包袋製作」。
2. 填寫「活動總名稱」，例如「2026文學季」。有比賽子項目時，另填「散文創作獎」等名稱；一般活動可留白。紅包袋都用同一個版型，不用另外選。
3. 填寫等第和數量，例如「佳作、3 份」。姓名可填可不填；同一筆可一次做多份。
4. 有多位得獎者，就按「新增一列」繼續填。
5. 按「產生紅包袋」，再按「下載 DOCX」。

## 獎狀怎麼做

1. 點「獎狀製作」。
2. 用下拉選單選「通用通識獎狀模板」或「文學季獎狀模板」。
3. 填寫科目或活動名稱、獎狀製發日期和署名職稱，例如「校長」或「主任」。文學季版另填「比賽子項目」，例如「散文創作獎」；八項比賽可分批製作。需要簽章時，可以選取自己的簽章圖片。
4. 設定「流水號起號」。字號中的日期會跟著你填的製發日期改變，畫面上可以先看首號和末號。
5. 填寫得獎者的姓名、科系班級和獎項。通用版另填學號；文學季版依原稿不列印學號。姓名可以填中文或英文；學號不限長度，也能有英文，開頭的 0 會保留。
6. 多人一起做時，按「新增一列」加入下一位。
7. 按「產生獎狀」，再按「下載 DOCX」。

例如製發日期填 `2026-11-24`、起號填 `1`，第一張的字號就是 `11511240001`，第二張是 `11511240002`。下次做另一批時，記得自行調整起號，避免重複。

## 用 Excel 或 CSV 批次匯入

1. 在「得獎者」按「下載 Excel 範本」或「下載 CSV 範本」。獎狀範本會依目前選的模板提供欄位。
2. 保留第一列的欄位名稱，從第二列開始填姓名、等第，以及需要的科系班級、學號。學號請用文字格式，保留開頭的 0。紅包袋的姓名可留白，「數量」未填時會用 1 份。
3. 按「匯入 Excel／CSV」選檔。Excel 請使用 `.xlsx`，並將名單放在第一張工作表。
4. 確認預覽後，按「取代名單」或「加入現有名單」。下方名單仍可直接修改；按「取消匯入」就保留原本資料。
5. 補齊其他資料後，按「產生獎狀」或「產生紅包袋」，再下載成品。

每批最多 200 頁，紅包袋依數量加總；匯入檔案最多 2 MB。資料不完整或超過上限時，會提示需要修正的位置。

## 下載後怎麼用

- **下載 DOCX**：用 Word 開啟成品，確認內容後列印。
- **下載 ZIP**：下載壓縮檔，解壓縮後裡面也是 Word 檔。
- **需要 PDF**：在 Word 裡選「另存為 PDF」。

獎狀與新版紅包袋都依 Word 範例使用「標楷體」。建議用 Windows 版 Microsoft Word 開啟，確認電腦已安裝標楷體，再列印或另存 PDF。

獎狀是 A4，紅包袋是 9 × 20 公分。列印時選「實際大小」或「100%」，避免版面被縮放。

## 用的時候注意一下

- 每批最多 200 頁。
- 產生後又修改資料，要再按一次「產生」，才會下載到修改後的成品。
- 關閉或重新整理網頁前，先把檔案下載好；填過的資料不會幫你保存。
